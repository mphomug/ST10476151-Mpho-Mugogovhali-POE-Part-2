CSS Styling and Responsive Design:
The Daily Grind Café website was styled using an external CSS stylesheet. The
stylesheet was linked to all five HTML pages to maintain a consistent design throughout
the website.
The website uses a warm café colour scheme with brown, cream and white colours.
Typography was adjusted using different font sizes, font weights, line spacing and letter
spacing to create a clear visual hierarchy.
Flexbox was used to arrange the header, café logo, website name and navigation links.
Sections, buttons, forms and other content were also styled using padding, margins,
borders, rounded corners and box shadows.
Responsive design was added using CSS media queries. The website was tested at
desktop, tablet and mobile screen sizes. The navigation, text, buttons, forms and other
content adjust to fit smaller screens.
Relative units such as percentages, rem and em were used to help the website adapt to
different screen sizes. Responsive image attributes using srcset and sizes were also
added
